# Wormhole feedback

Bug reports, ideas and questions for [Wormhole](https://wormhole.dryan.com), the
Mac app that lets Xcode and `devicectl` reach your iPhone or iPad on any Wi-Fi
network.

[Report a bug](https://github.com/dryan/wormhole-feedback/issues/new?template=bug.yml)
or [share an idea](https://github.com/dryan/wormhole-feedback/issues/new?template=idea.yml).

The app's source isn't public; this repository is only for feedback.

## Before you post

Issues here are public. Don't paste device names, IP addresses, Tailscale or
NetBird machine names, or anything from a device's pairing record (such as an
`authTag`). Replace them with placeholders like `my-iphone` or `100.x.y.z`.
